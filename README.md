# Онлайн-деканат

Локальный AI-помощник для предварительной проверки студенческих документов. Студент работает в браузере, сотрудник деканата — в нативном приложении. Оба клиента используют общий FastAPI, PostgreSQL и Ollama.

Сервис извлекает поля, проверяет обязательные сведения и показывает точные цитаты Положения. Окончательное решение принимает сотрудник. Наличие подписи или печати не означает подтверждение подлинности.

## Быстрый старт на Windows

Нужны **Docker Desktop с Linux-контейнерами**, **Python 3.12+**, **Ollama** и Git. Первичная установка моделей, образов и зависимостей требует интернета.

```powershell
git clone https://github.com/lllxxxlll69/hack2026.git
cd hack2026
ollama pull qwen3-vl:2b-instruct
.\Start-Docker.cmd
```

**Можно просто дважды нажать Start-Docker.cmd в папке проекта.** Запускатель создаёт .env при первом запуске через установленный Python, открывает Docker Desktop при необходимости, собирает API/PostgreSQL, ждёт готовности и открывает сайт. Python-пакеты для создания .env не нужны. Если команда py/python недоступна, установите Python и заново откройте терминал.

Обычно сайт доступен по **http://127.0.0.1:8000/**. Если порт занят, Windows-запускатель выбирает свободный в диапазоне 8000–8010. Фактический адрес показывает окно запуска — его же укажите в приложении деканата. Запускатель не устанавливает Docker, Python или Ollama и не скачивает модель автоматически.

### Ручной запуск API

Если Docker Desktop уже работает:

```powershell
py -3 scripts/setup.py
docker compose up -d --build --wait --wait-timeout 180
```

На Windows без команды py используйте python. Генератор сохраняет существующий .env и не меняет ключи или пароли.

### Первый вход

1. Откройте .env **локально у себя**, не публикуйте этот файл.
2. Логин первого сотрудника — значение BOOTSTRAP_USERNAME (по умолчанию dean).
3. Пароль — случайное значение BOOTSTRAP_PASSWORD из той же конфигурации.
4. Для работы деканата запустите нативный клиент по инструкции ниже.
5. В разделе «Аккаунты» создайте студента и передайте ему логин и временный пароль.
6. Студент входит в веб-кабинет и меняет временный пароль.

Общего пароля вида admin/admin нет. Самостоятельная регистрация отсутствует. Подтверждение аккаунта кодом для входа не требуется. Изменение BOOTSTRAP_PASSWORD в .env **не сбрасывает пароль уже существующего пользователя**.

## Нативное приложение деканата: Windows

Из корня клонированного проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe -m desktop.main
```

В окне входа задайте адрес API, например http://127.0.0.1:8000, и реквизиты сотрудника из .env. Токен клиента хранится в памяти, секреты в EXE не встраиваются.

Сборка собственного EXE:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1 -Name OnlineDean
```

Результат — dist/OnlineDean/OnlineDean.exe **вместе со всей папкой _internal**. Сборщик проверяет загрузку Qt, создание окна, рендер и кнопку входа в автономном режиме. Он ограничивает PATH только своего процесса, чтобы сторонние ICU DLL не ломали Qt. Готовые EXE и локальные папки dist/build в репозиторий не входят.

Не запускайте desktop/main.py напрямую: используйте модульный запуск из корня проекта.

## Если Docker не видит Ollama

Ollama работает **на компьютере пользователя**, не внутри контейнера. Контейнер обращается к http://host.docker.internal:11434. Активная модель для изображений и ответов — qwen3-vl:2b-instruct.

Проверка с компьютера:

```powershell
ollama list
curl.exe http://127.0.0.1:11434/api/tags
```

Проверка из контейнера:

```powershell
docker compose exec -T api python -c "import urllib.request; print(urllib.request.urlopen('http://host.docker.internal:11434/api/tags', timeout=5).status)"
```

Если Ollama слушает только loopback и контейнер не может подключиться, настройте OLLAMA_HOST=0.0.0.0:11434 и полностью перезапустите Ollama. На Windows это можно задать в пользовательских переменных окружения, на macOS для GUI-приложения — через launchctl setenv OLLAMA_HOST 0.0.0.0:11434 до повторного запуска приложения.

**Это расширяет адрес прослушивания Ollama.** Не публикуйте порт 11434 в интернет. Ограничьте доступ локальным брандмауэром и используйте только доверенную сеть. Запускатель автоматически настройки сети не меняет.

Если API работает, а модель недоступна, сайт и аккаунты откроются, но распознавание/AI не заработают. Требования к памяти и скорость зависят от компьютера; минимальная VRAM и производительность отдельно не измерялись.

## Возможности

### Студент: веб-кабинет

- Загрузка JPG/PNG/PDF, ручной или автоматический выбор типа.
- OCR-текст, оригинал и карточка извлечённых полей.
- Проверка комплектности, пропуски и цитаты требований.
- Вопросы по документу и Положению с источниками.
- Передача разговора сотруднику и переписка.
- История, поиск, фильтры и скачивание JSON.
- База правил с поиском по словам, синонимам и номеру пункта.
- Подготовленные документы по шаблонам.
- Смена пароля, досрочное удаление обращений или аккаунта.
- Адаптивная сетка и отключаемые анимации.

### Деканат: PySide6

- Очередь, фильтры, просмотр истории и ответы студентам.
- Редактирование OCR-полей с повторной проверкой.
- Подтверждение/отклонение с комментарием.
- Редактирование нормативных текстов, импорт TXT/Markdown.
- Управление шаблонами DOCX/TXT/Markdown.
- Новые пользовательские типы через конфигурацию.
- Создание студентов/сотрудников и отключение доступа.
- Выдача одноразового кода сброса пароля.
- Статистика, журнал действий, состояние API/модели.
- Кнопка запуска Docker, открытие веб-кабинета и анимации.

Текущий дизайн: фон #021823, панели #1D2C36, медный акцент #B47E5C. В вебе учитываются prefers-reduced-motion и настройка «Уменьшить анимации». В приложении анимации отключаются на текущий запуск в настройках или через DEAN_REDUCED_MOTION=1.

## Архитектура и стек

```text
Браузер студента ─┐
                 ├─ FastAPI + Uvicorn (Docker) ─ PostgreSQL 17 (Docker)
PySide6 деканата ─┘            │
                              ├─ зашифрованное файловое хранилище
                              └─ Ollama на компьютере пользователя
                                      qwen3-vl:2b-instruct
```

| Компонент | Технологии |
| --- | --- |
| API | Python 3.12, FastAPI, Uvicorn, Pydantic |
| БД | PostgreSQL 17, SQLAlchemy 2, psycopg 3 |
| Модель | Ollama, Qwen3-VL 2B Instruct |
| Фото и PDF | OpenCV, Pillow, NumPy, PyMuPDF |
| Клиенты | HTML/CSS/JavaScript/SVG, PySide6/Qt 6 |
| Сеть и загрузки | HTTPX, python-multipart |
| Пароли и шифрование | Argon2id, cryptography/Fernet |
| Шаблоны | docxtpl |
| Развёртывание | Docker Compose, PowerShell/CMD, shell |
| Сборка/проверки | PyInstaller, pytest, jsonschema, Ruff, Node.js |

OCR выполняет Qwen, отдельного Tesseract нет. Google Colab, облачный OCR/LLM, React, Electron и векторная БД не используются. qwen2.5:1.5b для текущего сценария не требуется; при необходимости задайте другую ANSWER_MODEL. SQLite используется только изолированными тестами/QA, не рабочим Compose.

### Путь документа

1. Сервер проверяет доступ и сохраняет зашифрованный оригинал.
2. Pillow исправляет EXIF-поворот, OpenCV мягко корректирует контраст при необходимости.
3. PyMuPDF рендерит PDF постранично.
4. Qwen определяет тип, затем отдельным запросом извлекает поля по JSON-схеме.
5. Для подписи/печати OpenCV предлагает области, Qwen классифицирует увеличенные фрагменты.
6. Python нормализует значения/даты и проверяет обязательность.
7. Ответ использует извлечённые значения и существующие пункты Положения.
8. Студент получает результат либо обращается к сотруднику.

Запросы к модели последовательно допускаются через asyncio.Lock внутри процесса. Распределённой очереди Celery/Redis нет. Документы и сообщения считаются недоверенными данными, а не инструкциями. Отсутствующие сведения нельзя дополнять из памяти модели. Эти ограничения снижают риск ошибок, но не гарантируют безошибочный OCR или абсолютную защиту от prompt injection.

## Типы, правила и шаблоны

Начальные типы: справка об обучении, заявление на академический отпуск, справка о практике. Полные требования и набор примеров: [пакет кейса](data/case/README.md).

Чтобы добавить пользовательский тип, сначала добавьте требования с уникальными номерами пунктов в базу правил, затем сохраните схему в разделе «Типы документов»:

```json
{
  "title": "Новая справка",
  "fields": [
    {"key": "student_name", "label": "ФИО студента", "kind": "string", "required": true, "rule": "7.1"},
    {"key": "signature_present", "label": "Подпись", "kind": "boolean", "required": true, "rule": "7.2"}
  ]
}
```

Ключи — латиница и подчёркивания, kind — string/boolean. Для даты можно задать format: "date". Нельзя удалять пункты, на которые ссылается схема. Базовые типы фиксированы для совместимости с проверкой.

Шаблоны содержат заполнители {{ student_name }}, {{ issue_date }} и другие ключи. Сервис подставляет поля последнего распознанного документа обращения. Если нужного значения нет, заполнение блокируется. DOCX сохраняет оформление исходного шаблона. Персональные сведения модель не сочиняет. Пример: [template-example.md](scripts/template-example.md).

Поиск BM25 с синонимами относится к интерфейсу просмотра базы правил. Комплектность «10 из 10» не является уверенностью OCR. Координатная подсветка всех полей на оригинале пока не реализована.

## Конфигурация и безопасность

Пример переменных: [.env.example](.env.example). scripts/setup.py генерирует отдельные случайные пароли и ключ Fernet через стандартную библиотеку Python. Не запускайте повторную генерацию поверх рабочих ключей.

- Пароли хэшируются Argon2id; БД хранит хэши сессионных токенов.
- Веб использует HttpOnly/SameSite cookie, нативный клиент — токен в памяти.
- Сессия действует 12 часов; пять неправильных паролей блокируют аккаунт на 15 минут.
- Смена пароля отзывает сессии; доступ проверяется сервером.
- Оригиналы, шаблоны, подготовленные файлы и чувствительное содержимое БД шифруются Fernet.
- Технические идентификаторы, логины, статусы и даты остаются открытыми.
- Обращения, файлы и переписка хранятся 14 дней от создания, сообщения срок не продлевают.
- Очистка запускается раз в минуту, после остановки сервиса — на следующем запуске.
- Журнал также хранится 14 дней, обезличенные статистические счётчики сохраняются отдельно.
- Multipart-парсер может использовать временные файлы: для защиты временного диска нужно системное шифрование.

SMTP для самостоятельного восстановления пароля необязателен и по умолчанию не настроен. Без SMTP сотрудник выдаёт одноразовый код сброса, действующий час. Этот код **не нужен для обычного входа**.

Шифрование при хранении не является сквозным: API и модель видят обрабатываемые данные. Ключ ENCRYPTION_KEY нужен для чтения сохранённого содержимого. Потеря ключа делает его недоступным.

### Работа с разных компьютеров

По умолчанию API и PostgreSQL слушают только 127.0.0.1. Для совместной сетевой работы нужен один общий API. Перед открытием доступа настройте HTTPS, разрешённые ALLOWED_ORIGINS, COOKIE_SECURE=true, брандмауэр и резервное копирование. Не открывайте PostgreSQL/Ollama в интернет. Готовое защищённое сетевое развёртывание в эту локальную конфигурацию не входит.

## Проверки и воспроизведение метрик

Для разработки на Windows после создания .venv:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt -r requirements-desktop.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check backend desktop tests
node --check web/app.js
node --check web/motion.js
node scripts/check-web.mjs
.\.venv\Scripts\python.exe scripts/desktop-design-smoke.py
```

Node.js нужен только для веб-проверок, не для рабочего сервера. API-тесты используют отдельную SQLite, GUI smoke — автономные фикстуры. scripts/preview.py — изолированный QA-сервер с тестовыми аккаунтами, **не запуск для рабочих данных**; его нельзя выставлять в сеть.

AI-прогон на открытых примерах требует установленной модели и .env:

```powershell
.\.venv\Scripts\python.exe scripts/benchmark.py --auto-type --output output/results.json
.\.venv\Scripts\python.exe data/case/evaluate.py --reference data/case/reference_results.json --predictions output/results.json
```

Для PDF добавьте --pdf; для короткого прогона --limit 3. Не смешивайте результаты разных моделей через --resume. Эталонная разметка используется оценщиком и тестами, но не подставляется в рабочее распознавание.

### Сохранённые результаты на 10.10.2026

30 PNG и 120 вопросов открытого синтетического набора:

| Метрика | qwen3-vl:2b-instruct (активный) | qwen3-vl:2b (ранний) |
| --- | --- | --- |
| field_accuracy_macro | 98,58% | 95,92% |
| validation_exact_match | 93,33% (28/30) | 100% (30/30) |
| question_exact_match | 98,33% (118/120) | 99,17% (119/120) |

Сохранённые отчёты и ограничения сравнения: [benchmarks](benchmarks/README.md). Метрика полей не означает посимвольную точность OCR; вопросы автоматически сравнивают value, answerable и sources, не весь свободный текст. Это не итоговый балл жюри и не гарантия качества на произвольных фото.

Instruct зафиксировал две пропущенные подписи, одну неверную дату и частичную транслитерацию ФИО. Протоколы прогонов различались: Instruct автоматически выбирал тип, ранний thinking-вариант получал тип из манифеста. Это не изолированный эксперимент над весами модели.

Проверка подписи/печати устанавливает только наличие отметки, не подлинность. Фиксированного лимита размера/страниц нет, но память и время ограничены. Один файл должен содержать один логический документ. Пилот на реальном вузе, нагрузочные измерения и macOS-сборка пока не проведены.

## Полезные команды и диагностика

```powershell
docker compose ps
docker compose logs --tail 100 api
docker compose logs --tail 100 db
docker compose up -d --build --wait --wait-timeout 180
docker compose stop
```

stop останавливает сервисы, тома сохраняются. **Не выполняйте down -v для обычного перезапуска:** эта команда удаляет тома с рабочими данными. Для резервной копии нужны согласованная копия PostgreSQL, файлового тома и защищённая копия .env с ключом шифрования.

| Симптом | Что проверить |
| --- | --- |
| Сайт не открывается | Docker Desktop, docker compose ps, фактический порт в запускателе |
| Сайт есть, OCR нет | ollama list, модель и доступ к Ollama из контейнера |
| Неверный пароль | База конкретной установки, реквизиты созданного аккаунта; изменение .env не сбрасывает пользователя |
| После входа доступны только настройки | Смените временный пароль |
| QtCore: DLL load failed | Пересоберите штатным скриптом, не копируйте случайные DLL и сохраняйте _internal |
| Порт 5432 занят | Остановите конфликтующий локальный сервер или измените публикацию порта db в compose.yaml |
| Старый дизайн после обновления | Ctrl+F5 / жёсткое обновление страницы |

Журналы Windows-запускателя — logs/docker-launch-*.log. Они локальные и исключены из Git. Команда для безопасной проверки без запуска контейнеров:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/deploy-docker.ps1 -CheckOnly
```

Правила и примеры относятся к учебному университету «Меридиан» и не являются нормативными актами настоящего вуза. Приложение не принимает административные решения за сотрудника.
