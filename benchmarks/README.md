# Сохранённые результаты открытого набора

Это копии отчётов прогона 10.10.2026, а не новая оценка при публикации репозитория.

- evaluation-instruct.json: qwen3-vl:2b-instruct, 30 PNG, 120 вопросов, автоматическое определение типа.
- evaluation-thinking.json: qwen3-vl:2b, 30 PNG, 120 вопросов, тип из манифеста.

Протоколы различаются: сравнение не изолирует влияние весов модели. Метрика полей не равна посимвольной точности OCR. Вопросы автоматически проверяют value, answerable и sources. Свободный текст answer требует отдельной демонстрационной проверки. Это не итоговый балл жюри и не гарантия работы на документах реального университета.

В рабочем распознавании эталонные значения не используются. Полный результат нового прогона создаётся локально скриптом scripts/benchmark.py; команда воспроизведения есть в основном README. Папка output исключена из публикации, поэтому файлы из README старой локальной версии могут отсутствовать здесь.
